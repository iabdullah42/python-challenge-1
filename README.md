# Food Truck Ordering System (Python CLI)

A command-line ordering program for a food truck. Customers browse a nested menu (snacks, meals, drinks, desserts), choose items and quantities, and get an itemized receipt with a total.

**Concepts:** nested dictionaries, loops, input validation, string formatting

**Run it:** `python menu.py`

**Tools:** Python
